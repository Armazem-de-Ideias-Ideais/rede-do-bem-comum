# Rede do Bem Comum · Common Good Network

Mapa e diretório bilíngue de iniciativas de autogestão, apoio mútuo, compartilhamento e bens comuns.

- `web/`: site estático (Cloudflare Pages, sem etapa de build). Configuração pública em `web/config.js`.
- `supabase/`: migrações reversíveis (Marcos B e C), Edge Function de e-mails, gerador de carga e testes pgTAP. Leia `supabase/README_DEPLOY.md`.
- `docs/`: arquitetura do lançamento, contrato da API e textos institucionais (minutas).
