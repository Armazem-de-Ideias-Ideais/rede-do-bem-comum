Estamos lanzando la Red del Bien Común, un mapa abierto y gratuito para acercar experiencias de autogestión, apoyo mutuo y bienes comunes en el mundo. Sin anuncios, con datos abiertos y código libre.

Cada iniciativa tiene una ficha, elige cómo aparece y puede salir cuando quiera. La Red muestra iniciativas, no personas: no guardamos direcciones ni listas de integrantes.

Para una red o movimiento como el suyo, puede ser una forma de presentar sus nodos locales y facilitar encuentros, intercambios y apoyos concretos, sin exponer a nadie. También pueden ayudar a difundirla entre las iniciativas que conocen, para que más gente se encuentre.
